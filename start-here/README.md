# Start here: A Python warm-up

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/utkukose/human-computer-interaction-NB-lecture/blob/main/start-here/NB00_start_here.ipynb)

This Colab notebook is for students who have never programmed in Python. It takes about one hour and covers what Week 1 assumes. The topics are how Colab works, cells and outputs, printing, variables and types, lists, loops, decisions, functions and the three libraries used throughout the course. NumPy handles arrays, pandas handles tables and Matplotlib draws plots. Every section ends with an exercise that checks the answer immediately. Students who already program in Python can skip it.
