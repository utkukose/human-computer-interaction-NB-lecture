Human-Computer Interaction

Prof. Dr. Utku Kose

RepositoryStart hereSyllabusPython path

A 14-week undergraduate course with lecture pages, interface clinics, 3D games and experiments in interactive labs, Colab notebooks that analyse the students' own interaction data, and a Python track for beginners. Each week starts from its overview, which gives the study path and links to the lecture page, the Colab notebook, the interactive lab and the PDF notes. The project of the course, the clinic app, runs through all weeks. Progress in the knowledge checks is stored only in this browser.
